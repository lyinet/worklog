# 周报导出

打开菜单 → 导出周报 → 选择时间范围 → 下载 Markdown。
文件名为「工作周报-YYYYMMDD-HHmm.md」，时间使用本地时区。

## 时间范围

- 本周：本地日历的周一到周日。
- 上周：上一周的周一到周日。
- 最近 7 天：含今天，向前取 6 天。
- 本月：本月第一天到最后一天。
- 自选日期：含开始和结束当天；倒置或无效日期不能下载。

## 内容

标题注明日期范围，概览显示记录条数和有记录的天数。
标签小节按条数降序，条数相同按名称排序，组内按记录时间正序。
多标签记录会分别出现在各标签组，但概览条数只计一次。
没有标签的记录归入「未分类」；真正的 #未分类 标签仍是独立组。
末尾附按天、按时间正序的时间线，保留标签。
各组及时间线的正文保留原文和行内标签，不删标签、不清理原有空格。
多行正文只增加 Markdown 列表续行缩进；纯标签原样保留，空白正文追加「（无正文）」提示。
空范围也可下载，显示 0 条和「这段时间没有记录」。

导出只读取当前记录，不修改记录，也不改变菜单里的原有 Markdown 和 JSON 导出。
日期筛选与分桶均使用 dayKey()，预设用本地日历日期构造，跨月、跨年及夏令时不按固定毫秒推算。

## 验证场景

- 390 × 844 和 320 px 宽度：菜单入口、四个预设、自选日期布局。
- 有多标签和无标签记录：条数、天数预览与下载内容一致。
- 空范围：说明文案可见，能下载空周报。
- 无效或倒置日期：显示提示，下载按钮禁用。
- 返回菜单、遮罩和 Escape：返回菜单；下载后关闭菜单，再打开默认为本周。
